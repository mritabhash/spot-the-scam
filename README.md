# Spot the Scam
## Digital Safety Essentials

An independent interactive eLearning demonstration by **Ritabhash Mondal**, Canberra, Australia.

Five short lessons help learners recognise suspicious messages, investigate phishing clues, practise safer decisions, and build a Pause. Verify. Report. response plan.

Includes illustrated learning cards, knowledge checks with feedback and retries, a six-card sorting activity, local progress saving, and a completion screen.

This repository contains the deployable production website only. The development repository is maintained separately. Browser-delivered JavaScript remains inspectable; minification is not source-code protection.

## Run locally

From this folder, run `python -m http.server 8000`, then open `http://localhost:8000`.

## Hosting

Deploy the contents of this repository to a static web host. Relative asset paths support GitHub Pages project hosting. No database, account service, or server-side application is required.

## Scope

Fictional training scenarios. An independent demonstration, not commissioned or government-endorsed. Progress is stored in the current browser. No LMS integration or completion certificate service is included.
